# Exemples “Paramètres + Brief page” (copy/paste)

Objectif : gagner du temps quand tu testes **“Proposer une structure”** dans le builder Website.

Chaque exemple ci-dessous contient :
- **Paramètres (global)** → à coller dans le bouton `Paramètres` du builder Website (Type de site Max UI + résumé + pour qui + but + ton).
- **Brief (page)** → à coller dans le panneau `Brief (page)` du builder (objectif + action attendue + messages essentiels + infos factuelles).

> Important : `Type de site (Max UI)` doit correspondre **exactement** à une valeur de `products.csv`.

---

## 1) Décoration intérieure (studio / indépendante)

### Paramètres (global)
```txt
Type de site (Max UI): Architecture / Interior
Résumé en 1 phrase: Site vitrine pour une décoratrice d’intérieur, avec galerie de réalisations et prise de contact pour devis.
Pour qui ? (public): Particuliers (30–60 ans) propriétaires/locataires qui veulent rénover ou re-décorer un appartement/maison.
But principal: Obtenir des demandes de devis qualifiées (budget, surface, délais) et booker un premier appel.
Ton / style rédactionnel: Chaleureux, premium, rassurant, simple (pas de jargon).
```

### Brief (page) — Accueil
```txt
Objectif: Montrer l’univers, prouver la crédibilité via portfolio, et convertir vers “Demander un devis”.
Action attendue (CTA): Demander un devis / Prendre rendez-vous (appel découverte 15 min)
Messages essentiels (1 par ligne):
Design sur-mesure, adapté à ton budget
Avant/après concrets + moodboards
Process clair en 3 étapes
Délais annoncés dès le départ
Accompagnement de A à Z (plans, shopping list, suivi)
Infos factuelles utiles:
Zone: [Ville + rayon] • Email: [email] • Téléphone: [téléphone]
Horaires: Lun–Ven 9h–18h • Déplacement: Oui/Non
```

## 2) Boulangerie / café de quartier (commande + click & collect)

### Paramètres (global)
```txt
Type de site (Max UI): Bakery/Cafe
Résumé en 1 phrase: Site vitrine pour une boulangerie-café avec menu, horaires, localisation, et commande en click & collect.
Pour qui ? (public): Habitants du quartier + salariés à proximité (petit-déj, pause déjeuner, goûter), 18–65 ans.
But principal: Augmenter le trafic en boutique + générer des commandes (précommande) et des avis Google.
Ton / style rédactionnel: Convivial, gourmand, local, authentique.
```

### Brief (page) — Accueil
```txt
Objectif: Donner envie immédiatement (produits phares), faciliter la visite (horaires/adresse), pousser la commande.
Action attendue (CTA): Commander / Voir le menu / Itinéraire
Messages essentiels (1 par ligne):
Fait maison chaque matin
Pains au levain + viennoiseries signature
Formules petit-déj et déjeuner
Précommande rapide (click & collect)
Ingrédients locaux quand possible
Infos factuelles utiles:
Adresse: [adresse] • Téléphone: [téléphone]
Horaires: Mar–Dim 7h–19h (fermé le lundi)
Parking / accès: [infos] • Allergènes: disponibles sur demande
```

## 3) Service B2B (cabinet / freelance : consulting, audit, studio)

### Paramètres (global)
```txt
Type de site (Max UI): B2B Service
Résumé en 1 phrase: Site vitrine pour une offre de conseil B2B (audit + accompagnement) avec prise de RDV et génération de leads.
Pour qui ? (public): Dirigeants/ops/marketing de PME & startups (10–200 employés) en recherche d’un prestataire fiable.
But principal: Générer des leads qualifiés (RDV) et vendre un audit d’entrée de gamme.
Ton / style rédactionnel: Clair, direct, crédible, orienté résultats.
```

### Brief (page) — Accueil
```txt
Objectif: Expliquer la proposition de valeur en 10 secondes, rassurer (méthode, preuves), convertir en RDV.
Action attendue (CTA): Réserver un appel / Demander un audit
Messages essentiels (1 par ligne):
Approche simple, mesurable, priorisée
Audit rapide + plan d’action en 7 jours
Exemples de résultats (chiffres)
Méthode en 3 étapes (diagnostic → plan → exécution)
Accompagnement flexible (forfait ou mission)
Infos factuelles utiles:
Localisation: [ville/pays] (remote possible)
Email: [email] • Calendly: [lien] • Téléphone: [téléphone]
```

## 4) Fleuriste / boutique de plantes (livraison locale)

### Paramètres (global)
```txt
Type de site (Max UI): Florist/Plant Shop
Résumé en 1 phrase: Site vitrine pour une boutique de fleurs et plantes avec collections, occasions, et demande de livraison.
Pour qui ? (public): Particuliers (cadeaux, événements) + entreprises (accueil, bureaux), 20–60 ans.
But principal: Générer des commandes (bouquets/abonnements) et des demandes de livraison locale.
Ton / style rédactionnel: Poétique, naturel, doux, mais orienté service.
```

### Brief (page) — Accueil
```txt
Objectif: Mettre en avant les collections et les occasions, rassurer sur la livraison, convertir vers commande/demande.
Action attendue (CTA): Commander un bouquet / Demander une livraison
Messages essentiels (1 par ligne):
Bouquets du jour et collections de saison
Livraison locale rapide (2–4h)
Compositions sur-mesure (mariage, événement)
Abonnements fleurs pour maison/bureau
Conseils d’entretien simples
Infos factuelles utiles:
Zone de livraison: [villes/quartiers] • Frais: à partir de [prix]
Téléphone: [téléphone] • Adresse boutique: [adresse]
Horaires: [horaires]
```

## 5) Photographe (portfolio + réservation)

### Paramètres (global)
```txt
Type de site (Max UI): Photography Studio
Résumé en 1 phrase: Portfolio de photographe (mariage / corporate / portrait) avec packs, disponibilités, et formulaire de demande.
Pour qui ? (public): Couples, indépendants, PME (shooting corporate), 25–55 ans.
But principal: Obtenir des demandes de devis + réserver des créneaux.
Ton / style rédactionnel: Minimal, élégant, humain, rassurant.
```

### Brief (page) — Accueil
```txt
Objectif: Montrer le style (portfolio), expliquer l’expérience, et pousser vers demande de devis.
Action attendue (CTA): Vérifier les disponibilités / Demander un devis
Messages essentiels (1 par ligne):
Style cohérent + retouche naturelle
Process simple (brief → shooting → livraison)
Packs clairs (durée, livrables, délais)
Galeries par catégorie (mariage, portrait, corporate)
Réponse sous 24h
Infos factuelles utiles:
Zone: [ville + déplacements] • Email: [email] • Téléphone: [téléphone]
Délai de livraison: [x] jours • Options: album/prints
```
